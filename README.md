# Sumatoria-de-arrBi---Diagonal-principal
Instrucciones:
-Dado el siguiente arreglo:

int[][] arrExample={
        {2,5,0,1},
        {5,1,9,5},
        {9,5,2,8},
        {4,0,0,4},
        {7,5,1,2}
    };

-Suma todos los elementos del arreglo, menos los de la diagonal principal
